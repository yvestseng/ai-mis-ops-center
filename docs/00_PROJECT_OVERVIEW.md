# 00 Project Overview

## 專案定位
AI MIS OPS Center 是企業內部資訊報修與 IT Operations Governance 系統。

## 核心能力
- User / Admin Portal
- 工單建立、查詢與處理
- P1 / P2 / P3 / P4 Priority Engine
- 公司、部門、單人影響範圍判斷
- 網路、Wi-Fi、Domain Login、Business App Outage 規則
- Classification Review / Quality KPI
- Human-in-the-loop
- RBAC / Audit / SLA / Survey
- Cloudflare Workers + D1 Release Evidence

## 結案原則
Feature Freeze 後僅允許 Security、Stability、Verification、Rollback、Handover 類變更。
