# 新增使用者功能修正說明

## 修正內容

1. 統一前後端密碼規則：至少 12 碼，且包含英文大小寫、數字與特殊符號。
2. 新增使用者表單加入帳號格式驗證與送出中狀態，避免重複送出。
3. API 錯誤會直接顯示於畫面，不再出現按下按鈕後無反應的狀況。
4. 後端新增角色、維運團隊有效性檢查。
5. 後端新增帳號與電子郵件重複檢查，回傳明確錯誤訊息。
6. 建立成功後自動重新載入使用者、角色、團隊與稽核資料。

## 建議測試資料

- 登入帳號：testuser02
- 初始密碼：由系統管理員建立測試帳號時設定
- 姓名：測試使用者 02

- 角色：一般使用者

## 驗證步驟

1. 使用系統管理員登入。
2. 進入「權限管理」→「使用者與角色」。
3. 點選右上角「新增使用者」。
4. 輸入符合規則的資料並送出。
5. 確認清單立即出現新帳號，密碼狀態顯示「可登入」。
6. 登出後使用新帳號與初始密碼登入。

## 注意

原始壓縮檔未包含 package.json、vite.config.ts、wrangler.jsonc 與完整建置依賴，因此無法在本修正版壓縮檔內執行完整 npm build。請將本壓縮檔中的修改檔案覆蓋到完整專案後再執行 npm run build 與部署。
