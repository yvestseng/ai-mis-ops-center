# 企業內部 AI 資訊報修系統網站原型

這是一個可直接開啟的前後台網站原型，依照規劃書與整合 Prompt 建立，涵蓋：

- 前台工作台、建立報修單、我的工單與問卷填寫
- 後台儀表板、工單管理中心、工單詳細頁
- AI 分析與人工覆核佇列
- SLA 政策、派工規則與逾期提示
- 知識庫治理與重大事件管理
- 系統使用問卷與 IT 人員服務調查
- 系統設定與稽核紀錄

## 使用方式

直接用瀏覽器開啟 `index.html`。

## 檔案

- `index.html`：網站結構與主要頁面
- `styles.css`：企業級 SaaS 介面樣式與響應式版面
- `app.js`：假資料、互動切換、工單篩選、AI 覆核與提示訊息

## 下一步建議

若要轉為正式系統，可依此原型拆成 ASP.NET Core MVC 或 Blazor 專案，並接上 MySQL、Microsoft Graph、AD/LDAP、AI Provider、背景工作與 RBAC 權限。
